## 实际修复

1.0.16 将主线程数据库读取移走时，唤醒接收器误用了内核启动时的设置快照，导致连接期间更改“唤醒时重置连接”不能立即生效。现在只将醒屏事件排入 IO 命令队列，在状态锁内读取最新设置：开启即重置，关闭即跳过；无需重新连接。屏幕接收器不在主线程读库。新增设备回归检查两次开关、实际出口、代次不变；正式 R8 验收从 UI 操作开关，检查完整周期没有重载或启动/停止命令。

Maestro 流程补充首次通知权限弹窗处理。正式验收入口先确认独立 S25+ 临时会话，再安装和注入公共夹具；只读复制数据库用于核对设置，不覆盖运行中的库。
