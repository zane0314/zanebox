# zanebox1.0.0 迁移与验收计划

目标：独立 Kotlin/Compose/Gradle 应用，只使用现有 AnyBox Go libcore。保持 AnyBox2.1.9 用户功能和数据语义，应用身份独立；仅模拟器验证，不发布。

## 工作顺序

1. 固定功能清单、数据/备份结构、配置与内核 ABI；核对可复用源码并记录来源。
2. 建立一个 app 模块、固定工具链、接入现有 libcore AAR；恢复 Gradle 构建和原生平台接口。
3. Kotlin 数据仓库、订阅/分享解析、规则/分组、备份恢复及统一配置流程。
4. :bg Kotlin 服务管理 VPN、状态、计量、网络恢复、选择与测速；AIDL 客户端提供唯一服务操作入口。
5. Compose 页面完整覆盖首页节点、智能分流、设置、编辑、导入/分享及备份等基线功能。
6. 核对生产自有源码无 Java/Smali、native 基线与版本身份；执行功能对照验收并修复失败项。

2026-10-05 状态：上述实现阶段与本轮明确验收范围已完成。最终九类模拟器、45项主机单元测试、349项native ABI检查PASS，失败项已修复并由新构建复验。用户指定首版保持1.0.0/1，仅内部debug产物。逐项证据和未覆盖边界见 `reports/final-acceptance.md`，不能将本轮PASS外推至所有真实服务器/设备。

## 核心不变量

- 服务拥有连接状态、monotonic 连接时间、会话编号及流量；UI 不重建会话。
- 默认节点、规则目标/组代表节点、测速结果各自建模；测速不隐式改变默认选择。
- 数据写入有事务/原子性与错误反馈；恢复失败不破坏原数据。
- 运行/测速/导出共享配置生成与校验规则，运行凭据只在运行输出中注入。
- 启动/停止/重载/切换串行；过期任务不能回写新会话。
- Go AAR 来自当前原生源码，并核对 ABI 与 16 KiB 对齐；不替换为上游 libbox。

## 验收

- 主机：数据/解析/备份往返/规则配置回归，Gradle 构建，最终 APK applicationId/version/dex/native 检查。
- 模拟器：原工程 tests/with_s25_emulator.sh 启动独立 S25+ 参数环境；冷启动、导入、连接/断开/重连、节点选择、测速、订阅、规则真实请求、分应用、分享、备份恢复、通知/磁贴、后台/熄屏/断网恢复、UI 长文本/字号、日志与服务恢复。
- 使用本地可控网络夹具以及必要的受控真实节点资料；敏感值不进入项目。模拟器网络切换能证明的范围明确记录。
- 每个功能写明 PASS/FAIL/NOT_TESTED 与证据；缺失或失败项必须保留，不以构建成功替代验收。

## 回退

原工程只读；新包名与数据隔离。任何迁移先在副本及模拟器上执行，原 AnyBox 用户数据及发布产物不受影响。
