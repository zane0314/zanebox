**验收证据**

- 115 项主机单元测试，0 失败、0 跳过；25 项设备回归的最新结果均 PASS。包括 v1/v2 迁移、并发写入、原生解析、真实路由/FakeDNS、连接回滚、自动应用、选择缓存、订阅并行及后台更新。
- 真内核 DNS 复验：服务先匹配时返回 FakeIP 并走 B；服务关闭后后置阻止生效；移除阻止后走 A；优先阻止仍拒绝。覆盖了修复中发现的拒绝规则优先级问题。
- 1000 节点、混合服务目标的 JVM 夹具，3006 个域名/IP 路由比较一致。路由 3019→29，关闭 FakeIP 的 DNS 3663→27，启用 FakeIP 的新 DNS 为 52 条。构建中位耗时约 31.5→10.6ms；只代表该夹具与本次主机样本。
- 最终正式包 1000 节点受控出口，3 次暖连接中位约 1837→842ms，包含 ADB 轮询。旧版首次启动包含资源提取，新版复用资源，两者首次启动数字不可当作公平冷启动对比。
- 最终 R8 包从 1.0.15 同 key 升级保留节点、分组和设置；前台 1s/息屏 10s、60s 落库及停止尾流有日志/数据库证据；无定时订阅时周期 reconcile 活跃数为 0；UI 启动阶段未发现主线程 Links 数据快照读取。
- 最终正式包：VPN 深度休眠、主进程被杀、WorkManager 任务抑制、系统电池豁免条件下，未打开 UI，订阅更新后 EXIT_B→EXIT_A，自动选择保持，两新节点延迟为正，约逾期 6s 完成；断开取消闹钟。
- Maestro 正式包连接、分流关闭、停止、版本及既有按压回归 PASS；Mobile MCP 辅助核对 PASS。每轮仅一个临时 S25+ 模拟器、无快照，收尾停止并清理其独立数据，电脑证据保留。
